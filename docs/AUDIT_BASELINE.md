# Audit baseline (Phase 1)

- **Starting commit:** `76d9cb2f2b86b49f9c564d8f374fdd2fed6f1688` (main, plugin 1.13.0), audited 2026-11-06.
- **Working branch:** `improve/2.0-hardening`.
- **Measured baseline:** 106 unit/integration tests pass in 12.6 s. Branch coverage is 93% over the `reqanalyzer` package (coverage 7.17.2).
  Ruff (default + B, SIM, RUF, PLW, TRY, UP rules) reports 32 findings. Bandit 1.9.4 reports 1 Medium (B310 `urlopen` scheme) and 9 Low (subprocess use).
- **Reproduction script:** `tests/test_security.py` (added in 2.0) re-runs each repro below as a regression test.
  The original repro output is quoted after each finding.

Severity: **Critical** = attacker-controlled code or data reaches the host without a boundary. **High** = a security or data-loss defect needing a plausible precondition. **Medium** = wrong or misleading behaviour, or limited DoS. **Low** = hygiene.
